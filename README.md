**SENSIATOR – Disaster Prediction and Management System**
SENSIATOR is a machine learning–based disaster prediction platform designed to forecast natural disasters such as floods, cyclones, and landslides using environmental parameters like rainfall, temperature, and wind speed.
The system uses Random Forest and Decision Tree algorithms for disaster classification and risk assessment. It also provides interactive data visualizations, city-wise disaster analysis, and nearby emergency service recommendations including hospitals, fire stations, police stations, and relief centers.
Features
Disaster prediction using Machine Learning
Risk level classification (High, Medium, Low)
City-wise disaster analysis
Exploratory Data Analysis (EDA) dashboards
Interactive visualizations using Matplotlib & Seaborn
Nearby emergency services locator
User-friendly web interface
